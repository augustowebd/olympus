Single monochrome line-icon set for navigation and dashboard indicators — replaces emoji, matches the ERP's professional tone.

```jsx
<Icon name="dashboard" size={22} />
```

Available names: dashboard, egg (produção), animal (manejo), feed (alimentação), box (estoque), cart (compras), truck (comercial), dollar (financeiro), wrench (patrimônio), users (RH), chart (relatórios), alert (avisos), eye (detalhar), edit (alterar), power (ativar/desativar), trash (excluir), file (exportar/documento), info (aviso neutro).
