Button

Variants: primary, secondary, ghost, danger. Alvo de toque mínimo 56px.

Input

Máscara automática dd/mm/aaaa para datas e pt-BR para valores monetários. Obrigatório com asterisco; desabilitado com fundo sunken.

Select

Opção neutra padrão sempre "Selecione".

Date Picker

Digitação livre com máscara dd/mm/aaaa + popover de calendário. Nunca o seletor nativo do navegador.
